# MirrorDock 项目开发团队 Agent

| 角色 | 拥有成果 | 完成条件 |
| --- | --- | --- |
| 交付负责人 | 路线图、决策/风险日志、发布 Go/No-Go | 每阶段范围、依赖、验收与责任人明确 |
| 桌面与媒体工程 | Tauri/Rust、ADB/scrcpy、渲染、会话、打包 | 三系统构建和连接路径有可复现验证 |
| Android 伴侣工程 | v1 MediaProjection、配对、前台服务、机型资料 | 逐会话同意/撤销与 Play 材料可审计 |
| UX/引导/客服 | 首次连接、错误恢复、帮助中心、客服脚本 | 非技术用户测试完成率和失败反馈闭环 |
| QA/设备实验室 | 真机矩阵、性能/稳定性、缺陷证据 | 按 OS、品牌、Android、网络切分的报告 |
| 安全与合规 | 威胁建模、权限、OSS、SBOM、渠道审查 | 未关闭的高风险/许可证/政策问题阻断发布 |

所有角色遵守 `AGENTS.md`。跨角色改动由交付负责人集成；任何成员可因权限、隐私、供应链或发布门禁问题阻断交付。

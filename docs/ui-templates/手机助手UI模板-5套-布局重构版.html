连接失败 / 设备不在线怎么办

无线 ADB 如何配对

同网段下用 mDNS 自动发现，或输入配对码 / 扫码完成一次性配对。

镜像黑屏或 early eof

先确认 adb 正常；抓 adb logcat 定位设备端 scrcpy-server 退出原因。

手机发来的文件看不到

进入文件传输页会自动加载设备目录；读取失败会置空并提示，不伪装成「没有文件」。

如何拖拽安装 APK

录像与 Pro 权益

通知镜像与隐私

多设备如何切换

桌面模式按设备设置

安卓伴侣 App 怎么装

NAS 版如何远程访问

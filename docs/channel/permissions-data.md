# 权限与数据清单（草稿）

> 桌面端（Tauri 应用）与设备端（Android 调试授权）逐项列出。发布前按渠道翻译。

## 桌面端

| 权限 / 能力 | 用途 | 触发条件 | 可撤销方式 |
| --- | --- | --- | --- |
| 执行 adb / scrcpy 子进程 | 设备发现、镜像、截图、传输 | 用户启动镜像或使用对应功能 | 关闭应用即结束全部子进程 |
| 局域网网络访问 | 无线调试配对与连接 | 用户显式输入配对码/端点 | 应用内「忘记此设备」或手机端关闭无线调试 |
| 应用数据目录读写 | 设置、最近设备、配对记录、许可证状态 | 应用运行 | 应用内逐条删除 / 撤销授权按钮 |
| 视频/图片/文档目录写入 | 截图、录像、文件传输、诊断导出 | 用户在系统对话框中选择目标 | 删除文件即可，应用不驻留 |
| 键盘 / 鼠标输入注入 | 镜像窗口内控制手机 | 仅在镜像会话中，只读模式下禁用 | 结束镜像窗口 |

**明确不做的**（与代码行为一致）：开机自启、后台常驻服务、全局钩子（镜像窗口外截取输入）、遥测上报、云同步、自动更新下载执行。

## 设备端（Android）

MirrorDock 不安装任何 Android 组件（伴侣 App 为 v1 后计划）。它使用的是 Android 系统自带的**USB / 无线调试授权**：

| 授权 | 谁授予 | 作用范围 | 如何撤销 |
| --- | --- | --- | --- |
| USB 调试 | 用户在手机上点「允许」 | adb 通道（截图/文件/镜像指令） | 手机开发者选项「撤销 USB 调试授权」 |
| 无线调试配对 | 用户输入配对码 | 同一局域网内 adb TLS 通道 | 手机端关闭无线调试 / 忘记配对 |

实测证据（2026-09-28 真机）：撤销 USB 调试授权后设备立即进入 unauthorized 状态；无线调试配对独立于 USB 授权，不会被连带清除。

## 渠道差异速览

- **国内**：桌面应用暂无应用商店强制审核的统一路径，主渠道为官网直接下载；需要准备工信部侧的网站备案（若提供下载官网）与软件著作权登记材料。
- **Google Play**：桌面端不在 Play 分发范围；Play 材料仅服务「Android 伴侣 App」（C4，v1 后）。桌面官网需声明与 Play 无关的分发与更新政策。
- **企业侧载**：以 SHA256SUMS + 签名包交付；提供内网更新说明与批量部署（MSI/DEB 静默参数）清单。

## 门禁（沿用 AGENTS.md）

安全、政策或许可证阻塞不能被产品指标豁免：签名证书未落实前，各渠道「可发行」状态一律标记为 ❌ 并注明缺失证据。

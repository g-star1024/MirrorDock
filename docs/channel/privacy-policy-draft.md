# MirrorDock 隐私政策（草稿）

> 状态：草稿。发布前需法务复核；内容必须与实际行为一致——下文每一条承诺都有对应的代码实现与测试证据。

## 一句话版本

MirrorDock 是**本地优先**的 Android 桌面镜像工具：画面、声音、按键、文件全部在你的电脑与手机之间直连，**不经过任何服务器**；没有账号、没有遥测、没有默认云存储。

## 数据流说明

1. **镜像数据（屏幕画面 / 音频 / 输入）**：由设备上的调试通道直连本机 MirrorDock 进程。不经第三方，不写日志。测试证据：真机会话测量只保留计时数据（test-runs/，Git 忽略）。
2. **授权密钥与许可证**：专业版许可证只保存在本机应用数据目录（entitlement.json），激活离线完成。许可证原文不会写入日志或诊断包（有单元测试断言）。
3. **诊断包**：默认不存在。只有你点击「预览诊断内容 → 导出为文件」时才生成，且只包含：应用版本、系统类型、镜像引擎可用性、事件列表（序列号、配对码、端点、路径、文件名、许可证一律脱敏为「[已脱敏]」）。是否发送给支持人员由你决定。
4. **本机设置**：会话选项、最近设备（上限 8 台）、已配对无线设备保存在本机；你可以逐条删除或撤销授权。
5. **更新检查**：当前版本不联网检查更新（如未来加入，会在此处更新本政策并默认关闭、显式开启）。

## 权限说明（桌面端）

- 访问 adb / scrcpy：仅用于与用户显式授权的设备通信；子进程一律固定参数直接调用。
- 文件系统：只在用户通过系统对话框选择的路径读写（截图、录像、文件传输、诊断导出）。
- 网络：仅局域网无线调试（用户显式配对后）；无任何对外服务。

## 用户权利

- 镜像会话随时可结束（窗口关闭 / 结束按钮），结束后无残留进程。
- 录像、截图、传输的文件全部落在用户可见的本机目录，可随时删除（应用内提供删除入口）。
- 授权可撤销：手机端撤销 USB 调试授权即刻生效；本机最近设备与无线配对记录可在应用内逐条移除。

## 儿童与受保护内容

MirrorDock 不绕过、也不会尝试绕过锁屏、DRM、`FLAG_SECURE` 保护页面或企业设备管理（MDM）。受保护内容在镜像中显示为黑屏是平台安全机制。

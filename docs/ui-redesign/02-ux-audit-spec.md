## 3. 信息架构规范

### 3.1 侧栏分组与排序（最终方案）

侧栏 232px（可折叠 56px，⌘B）。分组标题 11px/600 大写灰字。顺序遵循「连接 → 使用 → 内容 → 系统」的任务流：

```
◇（无分组）设备中心            ← 唯一的首页级入口，置顶
设备
  连接与授权
  设备信息
  多端
镜像与控制
  镜像控制          （高频，组内第一）
  投屏演示
  按键映射
  定时录制
  操作回放
内容
  文件传输
  相册
  截图
  录像
  批量安装
  应用管理
系统
  通知中心
  设置
  帮助中心
  Pro / 激活
```

- 与现状的差异：①「设备中心」提出分组置顶（它是无设备时的必达页）；②「镜像与会话」更名「镜像与控制」；③「内容与传输」更名「内容」并把相册提到截图/录像之前（浏览动线：传文件 → 看相册 → 单张截图/录像）；④ 删除侧栏底部「版本未知/本地优先·无需账号」块（=G12，并入状态条）。
- 收起态（56px）：仅图标 + tooltip 显示名称；分组标题隐藏，组间 8px 分隔线。
- 设备连接时，「连接与授权」项右侧显示绿点徽标（已连接 N 台）。

### 3.2 View Header（56px）文案模板

每页唯一页头：`标题 16px/600 + 副标题 12px/400 + 右侧主操作`。沿用 assistantViews.tsx 现有 title/subtitle/action 元数据，仅两处修正：

- settings.action：「偏好设置」→「恢复默认」（页头应放动作而非复述页名）；
- keymap.action：「打开键盘设置」降为次级按钮，主操作 =「新建方案」。

## 5. 交互细节规范

### 5.1 焦点顺序与 :focus-visible

- 全局 Tab 顺序：顶栏(Logo→⌘K→主题→帮助) → 侧栏 → View Header 主操作 → 内容区 → Context Panel → 状态条。
- 侧栏收起/抽屉打开时：抽屉为 modal，Tab 锁在抽屉内，Esc 关闭并归还焦点到汉堡按钮。
- `:focus-visible` 统一：`outline: 2px solid var(--focus, #4c8dff); outline-offset: 2px; border-radius: inherit;`。鼠标点击不出现（`:focus:not(:focus-visible)` 恢复默认）。
- 跳过链接：页面首个 Tab 元素为「跳到主内容」隐藏链接（视觉隐藏、聚焦显现），目标 = View Header。

### 5.2 键盘可达性

| 快捷键 | 行为 |
|--------|------|
| ⌘K / Ctrl+K | 命令面板 |
| ⌘B | 侧栏折叠 |
| 1–9（无修饰，命令面板外） | 跳转前 9 个常用视图（1=设备中心…9=相册），仅内容区无输入焦点时生效 |
| Esc | 关闭对话框/抽屉/命令面板；焦点归还触发元素 |
| Enter / Space | 激活按钮；表格行 Space=选中，Enter=打开行详情 |
| ← → | 相册 chips、Tab 组（顶栏若保留任何 tabular 元素）间移动（roving tabindex） |

### 5.3 危险操作确认模式（G6 落地）

| 操作 | 模式 | 细节 |
|------|------|------|
| 卸载应用（行内，可逆性无） | **对话框** | 标题「卸载 <应用名>？」正文「应用数据将一并删除，无法恢复。」主按钮 danger「卸载」+ 取消；输入应用名才可点确认（对系统级风险项） |
| 卸载/停用 批量 | 对话框 | 列出 N 项 + 同上 |
| 清空通知 | 对话框 | 「清空 N 条通知？」正文「通知正文默认不持久化，清空后无法找回。」 |
| 删除截图/录像/相册文件（行内单项） | **二次点击** | 首点按钮变红「确认删除？」，3 秒内再点生效；超时复原。同一时间只允许一个待确认项 |
| 结束镜像 / 停止录制 | 无确认（有 1s toast 可撤销式中断提示仅镜像） | 镜像结束 toast「镜像已结束 · [重新开始]」（5s） |
| 结束全部（multi） | 对话框 | 「结束 N 个镜像会话？」 |
| 撤销本机授权（pro） | 对话框 | 「撤销后本机回到免费版，激活码仍可用于再次激活。」 |
| 清空安装队列 | 二次点击 | 同上 |
| 修改快捷键/映射方案删除 | 二次点击 | 同上 |

对话框规范：宽 400px（批量列表 480px）；进入动画 150ms scale .98→1；焦点落主按钮（danger 时落在取消，防回车误触）；`role="alertdialog"` + `aria-labelledby`。

### 5.4 错误与提示文案模板

- 错误条（页面级）：`[图标] <一句结论> · [主 CTA] [查看详情]`，如「无法读取连接状态，可能是 adb 未就绪 · [重新检查] [详情]」。同页多条错误合并为一条聚合条。
- 行内错误（表单字段）：字段下方 12px 红字，含修复动作词（「请输入 6 位配对码」）。
- toast（成功/中性）：右下角，4s 自动消失，可含一个撤销动作；堆叠最多 3 条。
- 禁用原因（G8 落地）：禁用按钮必须满足二者之一 —— tooltip 说明原因，或改用「按钮文案即原因」模式（如「连接设备后可截图」）。

### 5.5 按钮 loading 态文案规范

- loading 中：按钮禁用、保留原宽（min-width 取常态宽度）、左侧 14px spinner、文案 = 动名词 +「中…」：`连接中… / 截图中… / 安装中… / 激活中… / 取回中…`。
- 永远不出现「Loading…」「请稍候」；超过 10s 的长任务（批量安装/取回相册）不在按钮上转圈，改为行级/卡级进度条 + 按钮变「停止」。
- 主操作完成：按钮文案瞬回，配合 toast 确认。

### 5.6 行内操作 vs 页头操作分工

- **页头（View Header）**：本页唯一高频主动作（开始镜像/立即截图/刷新清单）+ 至多 1 个次级动作（信息类，如「打开键盘设置」）。
- **行内（表格行/卡片）**：对象级操作（打开/卸载/删除/取回/停止该行），图标按钮 28×28 + tooltip；行内不出现 primary 色按钮（用 ghost），防与页头争夺视觉焦点。
- **卡头右侧**：该卡的刷新类动作（图标 28×28）。筛选/搜索只放在拥有数据的卡头，不放页头（G4 落地）。

## 7. 无障碍底线

1. **对比度**：正文/背景 ≥4.5:1；大字（≥18.66px bold 或 24px）≥3:1；禁用态豁免但视觉上仍 ≥3:1 为目标。Phase 1 tokens 落地后必测组合：① 主文本 on 玻璃 HUD 卡片背景（毛玻璃底变化大，取最深底色测）；② 灰字 placeholder（常见失败点，placeholder 允许 4.5:1 不豁免）；③ 黄色警告条底上的正文（现状 `home-*.png` 黄底深字需实测 ≥4.5:1）；④ 状态条 28px 内 11px 小字。
2. **目标尺寸**：鼠标目标 ≥24×24（WCAG 2.2 AA 2.5.8），行内图标按钮 28×28，页头按钮高 32px；触控/平板场景 ≥44×44。相邻可点目标间距 ≥8px。
3. **aria 要点**：
   - 侧栏 `nav aria-label="主导航"`；当前项 `aria-current="page"`。
   - 表格容器 `role="region" aria-label="<卡名>" tabIndex=0`（现状已做，保留）；表头用 `<th scope="col">`。
   - 命令面板 `role="dialog" aria-modal`，列表 `role="listbox"` + `aria-activedescendant`。
   - 开关用 `<button role="switch" aria-checked>`；折叠项 `aria-expanded`；对话框 `role="alertdialog"`。
   - 状态条更新用 `aria-live="polite"`（连接状态变化读屏可感知）；toast `role="status"`。
   - 动态区（画布/骨架屏）加 `aria-busy="true"`。
4. **键盘陷阱**：抽屉/对话框/命令面板打开时 Tab 循环限制在其中；Esc 关闭归还焦点。
5. **动效**：`prefers-reduced-motion: reduce` 时关闭骨架 shimmer、面板 scale 动画、toast 滑入。

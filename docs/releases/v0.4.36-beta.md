## 客户端样式与预览全面对齐（X10-156 / X10-157 / X10-157b）

本版是一个纯前端样式对齐版本：客户端 19 个视图的组件语言全面对齐重构预览，用程序化比对（Playwright 采集 19 视图 × 27 类组件 × 16 项计算样式 + diff 脚本）替代目测，首轮 55 条差异清零，复测剩余 28 条均确认为假阳性。

### 全组件语言对齐预览

- **按钮**：39 处旧按钮类（primary-button / secondary-button / danger-stop / text-button）全部替换为预览的 `btn / btn-primary / btn-secondary / btn-danger / btn-ghost / btn-sm` 家族（32px / 26px 两档规格）；按钮组统一 `action-row` flex 容器（修复扫码配对、常驻通道等 6 处按钮贴死问题）。
- **卡头**：设备中心 / 连接页各卡头改为预览同款 `head-row`（badge + 标题同行）；帮助文章、设置卡卡头统一 12/20 内边距与分隔线。
- **步骤**：数字圈改为预览的 6px 圆点 + 12px 说明文字。
- **白卡化**：device-card / capability-panel / 品牌引导统一白底 + 发丝线 + 6px 圆角、无投影；诊断条改为预览左色条 alert 样式。

### 设置中心对齐（X10-157）

- 左侧分组导航补齐 7 个图标（对齐预览），文字改常规字重，选中态 accent-soft + accent；断点行为与预览逐字一致（1199px 以下横排 chips）。
- 页头对齐预览 `.vh` 规格：20px 粗标题、吸顶通栏；右上按钮为「恢复默认」次级钮。
- 主题卡改白底 + 选中蓝色外圈 ring；设置行 13px/500 标题 + 12px 说明。
- 6 张设置卡卡头去装饰性说明；**版本与授权的动态状态（版本 / 许可证号 / 到期时间）完整保留进 badge，一个不丢**。

### 设备中心（未连接）对齐

- 「按品牌查看开启步骤」从连接卡内嵌框改为预览同款独立卡片（卡头 + 分隔线 + 卡身）。
- 三步说明统一 12px、引导标题粗体。

### 页头按钮对齐预览

连接页 = 重新检查、设置 = 恢复默认（次级 32px）；其余视图按预览不再渲染页头按钮——功能全部保留在卡头 / 卡脚 / 卡内（刷新文件、立即截图、清空通知、选择 APK 等逐项核实过）。

### 说明

预览的「演示数据 / 模拟加载」开关不搬入客户端（真实状态原则：不伪造数据）。

### 已知边界

APK 与桌面端真机行为仍以 Release 资产实测为准；macOS 未公证（右键打开或 `xattr` 放行）。

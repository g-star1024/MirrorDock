# MirrorDock v0.4.9-beta

## 本版更新内容

### 界面优化：文件传输列表（X10-75）

「工具」页的文件传输列表重新设计了一遍，只改界面与文案提示，不动任何功能。

**操作列不再参差**

之前每一行各自决定按钮位置，文件名长短不同，按钮就跟着错开。现在整个列表用同一套列宽对齐，无论文件名多长、处于哪种状态，按钮都在同一位置。

**取回后状态明确**

点「取回到电脑」后，这一行会变成「已取回」并标绿，不再重复显示同一个按钮。正在进行的那一行单独显示进度，不会整张表一起转圈。

如果没取回成功，原因会显示在**那一行**里，并提供「重试」——不用刷新整个列表重来。

**「在文件夹中显示」移到面板顶部**

之前每一行都有这个按钮，但它们指向的其实是同一个文件夹。现在顶部只有一个「打开文件夹」，下面也直接写明「取回后保存在 下载 / MirrorDock」，一眼就知道文件会去哪。

**删除前会先确认**

「删除」在文件已取回后有两种可能的含义（删手机上的原件，还是删电脑里的副本），点之前无从判断。现在会先弹确认，写明删的是哪一份、电脑里的副本不受影响。

**长文件名不再被截掉关键信息**

文件版本号、`.apk` 后缀都在文件名末尾，之前的单行省略号恰好把这些最值钱的信息砍掉了。现在文件名最多显示两行，「我该用哪个版本」这个问题能自己看出来。

**其它优化**

- 文件按用途分组：安装包、文档、其他文件，标题带数量。
- 列表底部一句话说明进度：「共 8 个文件，3 个已取回」。
- 术语统一：全篇只说「取回」，不再混用「保存到」「复制到」。
- 字号建立层级（文件名 14px、元信息 12px、按钮 13px），中文在小字号下发糊的问题缓解。

---

MirrorDock 桌面镜像工具测试版。本地优先：画面、截图、录像与文件传输只经过你自己的数据线或局域网，不上传任何服务器。

**下载哪个文件**（文件名含版本号，按后缀识别即可）

- Windows：`...-setup.exe`（安装版）或 `....msi`
- macOS（Apple 芯片 M1 及以后）：`..._aarch64.dmg`
- macOS（Intel）：`..._x64.dmg`
- Linux：`....AppImage`（免安装）/ `.deb` / `.rpm`
- 手机伴侣 App：`app-debug.apk`

**安装后怎么开始**

1. 电脑端打开 MirrorDock → 用数据线连手机，或选「无线连接」。
2. 手机开启「开发者选项 → USB 调试 / 无线调试」。Android 11 及以上可直接用「无线调试 → 使用二维码配对设备」扫电脑上的二维码。
3. 需要伴侣 App 时安装 `app-debug.apk`，与电脑在同一 Wi-Fi 下扫码建立加密连接。覆盖安装会保留已配对的电脑。

**本版说明**

- 测试版**已内置永久激活码，无需手动激活**；在「设置 → 版本与授权」点击撤销后可选择不再自动激活。
- 本版为 **debug 签名的测试版**，未做代码签名与公证。
- 未做自动更新：升级请回到本页面下载新版本。
- 受保护内容（支付、密码页）系统会屏蔽为黑屏。

**校验与透明**

- 每个平台的 `SHA256SUMS-<平台>.txt` 为对应安装包的校验值，建议下载后核对。
- `sbom-cargo-*.json` / `sbom-npm-*.json` 为依赖清单（SBOM）。

## 外观升级

- MirrorDock 桌面端换成更接近桌面助手的外壳：顶部一级模块导航与工具栏、左侧设备树与功能导航（19 个功能入口）、中央工作区、右侧设备状态栏、底部连接状态条。
- 左侧功能树的 19 个视图对齐手机助手原型：设备中心、连接与授权、设备信息、多端、镜像控制、投屏演示、按键映射、定时录制、操作回放、文件传输、截图、录像、相册、批量安装、应用管理、通知中心、设置、帮助中心、Pro / 激活。已有真实能力的页面直接接入现有逻辑，暂无对应能力的页面显示真实状态说明与入口指引，不使用演示数据。
- 新增 5 套外观主题：**云鲸桌台 / 深空控制台 / 彩色磁贴 / 极简留白 / 玻璃 HUD**。在「设置 → 外观主题」里切换，只改变这台电脑上的视觉样式。
- 主题偏好只保存在本机，不上传、不需要账号；首屏启动前会恢复上次选择，避免默认蓝白闪一下。

## 新能力（能力层）

- **批量安装**：一次选择多个 APK，逐个安装到手机；每个安装包显示 adb 的真实结论（成功 / 失败原因），单个失败不阻断后续，可随时停止。
- **相册**：浏览手机的 DCIM / 相机 / 图片 / 截图目录（固定白名单，不做自由路径浏览），把照片和视频取回到本机「下载 / MirrorDock / 相册」。
- **按键映射**：把电脑键盘的物理键映射为注入动作（Android 按键 / 点击 / 滑动），方案保存在本机；提供聚焦测试面板直接试用。
- **操作回放**：编排点击 / 滑动 / 按键 / 等待序列并按序回放到手机，逐步显示执行结果；脚本保存在本机。
- 以上输入能力只接受白名单按键码与限定范围坐标，未授权设备不会收到任何注入。
- **定时录制**：创建本机录制计划（开始时间 + 时长），到点自动开始录制、时长到自动结束；计划保存在本机，运行结果（成功 / 失败原因）如实在列表中展示。计划只在本应用运行时触发，不做开机后台拉起、不绕过设备授权；到点时设备需已有镜像会话。
- **多端操作**：多端视图里每台设备可以直接「镜像」/「截图」，不再只是只读列表。
- **投屏演示**：提供真实就绪检查（设备 / 镜像引擎 / 桌面模式 / 活动会话），一键按当前设置发起演示会话，可随时结束；白板标注等未实现能力如实标注。
- **通知本机保留**：通知中心新增可选开关，开启后通知在本机保留（最多 50 条，重启恢复），默认关闭；内容不出本机。
- **应用管理**：每个应用可「打开」（系统默认入口启动）或「卸载」（先弹确认，卸载后无法恢复；系统预装应用无法卸载），卸载成功后清单自动刷新。
- **通知直达**：每条通知可一键「打开」来源应用，把 App 拉到手机前台。
- **设备信息**：新增电池（电量 / 充电状态 / 温度）与存储（总容量 / 可用）只读摘要，进入页面自动读取，可手动刷新；读不到的字段如实显示，不猜数值。
- **拖拽安装升级**：拖入 1 个 APK 保持直接安装；拖入多个 APK 会全部加入批量安装队列（不再只装第一个），自动切到批量安装页供你确认。
- **相册一键取回**：一个按钮按顺序取回当前目录所有未取回的照片 / 视频，单个失败不阻断其他文件。
- **多端一键全部截图**：对所有就绪手机各截一张，文件名带设备序列号不会互相覆盖，结论逐台展示。
- **方案与脚本备份**：按键映射方案、回放脚本可以导出成 .json 文件、在其他电脑上导入恢复；导入内容逐条校验，坏条目自动跳过，文件只存本机。

## 界面统一与伴侣端新能力（能力层）

- **全 19 视图统一组件语言**：设置中心之外的所有页面（多端 / 镜像 / 按键映射 / 定时录制 / 操作回放 / 应用管理 / 录像 / 投屏演示等）与首页 / 连接 / 帮助一并对齐到统一的卡片语法——圆角唯一 12px、柔影分层、卡头标题唯一出处；信息架构重排，**功能项零丢失**。
- **设置中心分组导航**：7 组真实设置项（外观主题 / 通用 / 镜像窗口 / 设备与桌面模式 / 全局快捷键 / 版本与授权 / 关于）改为左侧分组导航，只重排信息架构，不删不改任何设置项。
- **验证码复制**：通知中的验证码自动识别并显示「复制验证码」按钮，保守识别（只认高置信格式），点击写入本机剪贴板。
- **通知下行清除**：电脑端可单条清除或一键清空手机通知（走既有加密通道，精确匹配后取消，不误伤其他通知）。
- **手动双向剪贴板**：手机伴侣端新增「发送剪贴板到电脑」按钮（点按钮才读，不后台监听、不加权限）；电脑端「发送到手机」的文字写入手机剪贴板。长度上限 6000 字节，超限如实提示。
- **预览 ↔ 客户端双向对齐**：重设计预览补齐客户端已有的诊断导出、电池存储、批量截图、剪贴板等真实入口；演示占位按钮全部改为可交互或移除，不保留假入口。

## 不变的部分

- 本版只做 UI 对齐与新输入能力，不加账号 / 云端 / 新系统权限。连接授权、USB / 无线配对、镜像窗口、文件传输、截图、录制与授权逻辑都没有改动。
- 设备列表、连接状态、会话数、镜像引擎状态与版本号都是真实值，不使用演示数据。

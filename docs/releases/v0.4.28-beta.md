## 外观升级

- MirrorDock 桌面端换成更接近桌面助手的外壳：顶部一级模块导航与工具栏、左侧设备树与功能导航（19 个功能入口）、中央工作区、右侧设备状态栏、底部连接状态条。
- 左侧功能树的 19 个视图对齐手机助手原型：设备中心、连接与授权、设备信息、多端、镜像控制、投屏演示、按键映射、定时录制、操作回放、文件传输、截图、录像、相册、批量安装、应用管理、通知中心、设置、帮助中心、Pro / 激活。已有真实能力的页面直接接入现有逻辑，暂无对应能力的页面显示真实状态说明与入口指引，不使用演示数据。
- 新增 5 套外观主题：**云鲸桌台 / 深空控制台 / 彩色磁贴 / 极简留白 / 玻璃 HUD**。在「设置 → 外观主题」里切换，只改变这台电脑上的视觉样式。
- 主题偏好只保存在本机，不上传、不需要账号；首屏启动前会恢复上次选择，避免默认蓝白闪一下。

## 不变的部分

- 本版只做 UI 对齐，不加新硬件能力。连接授权、USB / 无线配对、镜像窗口、文件传输、截图、录制、快捷键与授权逻辑都没有改动。
- 设备列表、连接状态、会话数、镜像引擎状态与版本号都是真实值，不使用演示数据。

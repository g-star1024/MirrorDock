## 新增

- **应用管理加「导出 APK」**（X10-167）：每行新增「导出 APK」按钮，`pm path` 拿全部 APK 路径（base + split_*.apk），逐个 pull 到本机「下载 / MirrorDock / APK / <包名>」，成功后定位导出目录。支持 split APK（一次导出多文件）。
- **设备控制与性能**（X10-168）：设备信息页新增「设备控制与性能」卡片——亮度滑条（0-255）、音量滑条（0-15）、性能快照（CPU 占用 / 内存 / 电池温度）。滑条拖动 300ms 防抖提交，避免 adb 命令风暴；读不到字段如实为空，音量越界如实拒绝。
- **存储分析与文件搜索**（X10-169）：设备信息页新增「存储分析与文件搜索」卡片——存储卷摘要（总 / 已用 / 可用）+ 公共存储顶层目录占用条；按文件名全盘搜索（`find -iname`），跳过低权限目录。搜索关键词含 shell 危险字符如实拒绝。
- **录屏转 GIF**（X10-170）：录像页新增「转为 GIF」，把已结束的录屏 .mp4 转成同目录同名 .gif（本机 ffmpeg，12fps、宽 480 等比缩放、无限循环）。ffmpeg 缺失时如实提示安装命令，不降级为假转换。

## 优化

- **文件管理体验细节**：目录占用条按「已列目录字节和」为基准（避免与 df 口径不一致导致超过 100%）；搜索结果显示前 50 条并如实提示总数。
- **通知中心与剪贴板**：通知历史（实时镜像 / 复制验证码 / 快捷回复 / 本机保留）与剪贴板双向同步（手机→电脑复制、电脑→手机发送）已具备，本版确认覆盖用户需求。

## 新增

- **文件管理**（X10-166）：在助手页新增「文件管理」，通过 adb 直接浏览手机公共存储，支持完整读写。
  - 浏览：逐级进入目录、面包屑逐级回退、文件夹恒排前。
  - 读写：上传（多选本地文件到当前目录）、下载（保存到本机 `下载/MirrorDock/文件管理` 并定位）、新建文件夹、重命名、删除（目录需显式确认，删除的是手机原件）。
  - 目录内搜索：按名称过滤当前目录。
  - 诚实边界：`Android/data`、`Android/obb`、应用私有目录与 `/data` 等如实拒绝（不假装能进）；读取失败置空报错（不伪装成「空目录」）。
  - 后端：`list/push/pull/remove/mkdir/rename_phone_entry` 六命令，路径白名单校验（拒 `..` 逃逸与受限目录）、`ls -la` 解析（含空格文件名安全重组）、toybox 修改时间解析用纯整数算法（不引入 chrono）。

## 优化

- **设备中心高度对齐预览版**：`.device-hero` 去掉固定 100px 大盒、改自然高度图标列；设备名 26→16px、状态 chips 10→4px、分隔线拉伸、内边距 18→20px。Playwright 实测 114.8px vs 预览 112px（差 2.8px < 3%）。
- **相册 + 应用管理懒加载**：首次进入不再一次性渲染全部内容，首屏只渲染 120 条，底部「加载更多（还有 N 条）」每次 +120；筛选 / 搜索 / 排序变化自动回到首页，显著改善大量媒体 / 应用时的首屏卡顿。

# MirrorDock v0.4.21-beta

## 修复

### 桌面模式录制：Mac 白屏 / Windows 视频不完整（X10-101）

桌面（虚拟屏）模式下录制的视频，Mac 端整段白屏、Windows 端播放器提示「视频不完整」。两者同根——此前给录制进程固定了「无控制」标记，而 scrcpy 在无控制 + 无窗的状态下不会驱动虚拟屏渲染/刷新：Mac 上录到一块空白屏，Windows 上几乎不产生有效帧、时间轴残缺。

本版让桌面模式录制开启控制通道、并由录制进程自行拉起要录的应用。修复后桌面录制恢复 ~20fps、录到虚拟屏真实画面（真机实测梦幻西游）。手机屏幕 / 摄像头源的录制不受影响。

## 实测验证

- 桌面模式（虚拟屏）录制：152 帧 / 7.9s ≈ 19–22fps，录到真实游戏画面（此前为白屏）。
- 对照：录手机真实屏幕在修复前后均正常，问题专属于虚拟屏录制。

## 升级

- **自动更新**：打开应用按提示升级到 0.4.21。
- **手动安装**：从 Release 资产下载对应平台安装包覆盖安装即可。
- **完整性**：四平台安装包均带 Ed25519 签名校验，更新通道安全。

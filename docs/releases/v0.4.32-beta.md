## 修复与增强

### 重构预览 v3.0「安静诊断台」设计系统落地（X10-152）

客户端整体视觉按 `docs/ui-redesign/mirrordock-rebuild-preview.html` 采纳，解决「0.4.31 与预览版观感不一致」的反馈。保真原则：只换组件类与 CSS，不动任何 state、事件、文案与条件分支；设置中心只重排信息架构、零丢项。

- **差异化圆角**：统一 12px → 5 档圆角（surface 2px / control 4px / card 6px / panel 8px / 药丸 999px），卡片、按钮、控件各归其位。
- **扁平化**：顶栏去渐变、卡片与浮层去重影，改为 surface 分层 + 发丝线（hairline）分隔；按钮去渐变与光晕，改为纯色 + hover 加深。
- **字距标尺**：7 档字号（11–28px）+ 4px 间距标尺（--sp-1…12）贯穿全局；正文基准 13px。
- **5 套主题色板细化**：云鲸/深空/磁贴/留白/玻璃 逐套对齐预览终值（mist/midnight/porcelain/ember/frost），保留用户可见名称与 data-theme 键。
- **骨架对齐**：左栏 232px（折叠 56px）、情境右栏 280px、内容区 1600px 上限 + 呼吸边距；顶栏 44px、状态条 28px。
- **组件语言**：卡片/表格/徽章药丸/状态点/开关/步骤点线/kv 网格/空态/工具格/方案卡/拖放区/通知行全部按预览组件库收口。

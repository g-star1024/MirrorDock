## 镜像控制页清退假画布（界面层）

- 镜像 / 演示画面一律在**独立的镜像窗口**打开，「镜像控制」页不再显示假画布（此前的装饰性手机框与空白画布已移除）。页面改为真实的「镜像状态」卡：会话是否进行中、阶段、首帧是否到达，一眼可读；下方保留会话参数与开始 / 结束 / 设备信息操作。
- 「投屏演示」页说明同步明确：画面在独立窗口全屏投到外部显示器，控制页不重复显示画面。

## 布局细节修正

- **窗口放大内容跟随放大**：此前工作区内容被固定在约 1020px 宽，放大窗口后两侧留白不变；现放宽上限，内容随窗口增长（外接大屏 / 全屏时表格、分栏明显更宽敞）。
- **四向边距统一**：内容区与页面标题条边距统一为 24px，元素不再贴边。
- **长文案不再被裁切**：会话参数等键值卡里的长说明（如「录制经既有会话，不绕过授权」）此前被截断，现正常换行完整显示。
- **空提示条修复**：文件传输页在无任何消息时会渲染一条空的蓝色提示条，现已移除；各页提示只在有真实内容时出现。

## 不变的部分

- 本版只做界面与布局修正，不加账号 / 云端 / 新系统权限；连接授权、镜像、文件传输、截图、录制与授权逻辑都没有改动。镜像引擎、会话行为与 v0.4.28 完全一致。

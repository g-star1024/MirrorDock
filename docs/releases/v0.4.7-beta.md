# MirrorDock v0.4.7-beta

## 本版更新内容

### 修复：「按设备设置」模块形同虚设（X10-72）

上一版把桌面模式与虚拟屏启动应用改成了按设备保存，但入口只在**两台以上设备正在镜像**时才渲染，单台设备或未开始镜像时读写会落到全局设置——界面上就是一个普通开关，你反馈的"看起来还是全局设置、找不到按设备设置的模块"属实。

本版把它做成真正独立、始终可见的一页：

- 新增「按设备设置 · 桌面模式」独立区块，从「镜像窗口」里移出。
- 设备下拉列出**所有**已知设备：已连接的排在前面，没插线但以前设置过的、未授权的、离线的都会列出——可以提前配好再插线。
- 每个设备一行，直接显示这台机器当前的桌面模式开关状态；点一行就切换到编辑它。
- 明确标注「下面两项正在编辑：<设备名>」，每一项的说明里也写明"仅对某台设备生效"。
- 只有在一台设备都没有时，才回落为全局默认，并在界面上如实写明这一点。
- 删掉了原先"多台设备时按应用到哪台设备单独保存"的说法——那句话在单设备场景下是假的。

### 伴侣 App 重构为三页结构（X10-73，0.2.5 → 0.3.0）

伴侣 App 的功能越来越多，原来的单页长滚动已经装不下了：配对、文件、通知镜像、崩溃记录、运行日志全挤在一屏，找入口很费劲。本版按 ToDesk 的信息架构重做结构与交互，**配色保持青碧不变**。

**设备页**（新的首页）

- 顶部是连接状态卡与连接质量面板：延迟、已连接时长、端到端加密。延迟是实测的往返毫秒数，采不到样时显示「—」而不是 0（0 会被读成"延迟极低"，那是假的）。
- 「我的设备」列表支持**多台电脑**：每行显示名称、在线/离线、分组、地址与身份、上次连接时间。点整行切换到这台，点「⋯」可以重命名、归入分组、解除这一台。
- 状态如实：只有常驻连接真的建立且对得上号才显示"在线"，其余一律"离线"，不让你以为能连。
- 分组筛选（全部 / 各分组 / 未分组），只有一台时不显示（那时筛选没意义）。
- 可把「连接上次配对的电脑」**添加到桌面快捷方式**，点一下就连上。由系统弹窗确认，不会未经同意出现在桌面。

**文件页**——电脑发来的文件与「发送文件到电脑」提升为独立入口，不再是长滚动里的一张卡。

**设置页**——通知镜像、屏幕捕获、互信管理、隐私说明、运行日志（默认收起）。

**多设备的实质变化**：以前配第二台电脑会**覆盖**掉第一台的凭据；现在每台电脑的凭据独立保存，可以随时切换。解除互信也只解除你选的那台，其它电脑不受影响。覆盖安装时旧凭据会自动迁移，你不需要重新扫码。

**兼容性**：协议对旧版桌面端双向兼容——旧版桌面端收到新 App 的心跳会正常忽略多余字段，新 App 连旧版桌面端也照常工作。

---

MirrorDock 桌面镜像工具测试版。本地优先：画面、截图、录像与文件传输只经过你自己的数据线或局域网，不上传任何服务器。

**下载哪个文件**（文件名含版本号，按后缀识别即可）

- Windows：`...-setup.exe`（安装版）或 `....msi`
- macOS（Apple 芯片 M1 及以后）：`..._aarch64.dmg`
- macOS（Intel）：`..._x64.dmg`
- Linux：`....AppImage`（免安装）/ `.deb` / `.rpm`
- 手机伴侣 App：`app-debug.apk`

**安装后怎么开始**

1. 电脑端打开 MirrorDock → 用数据线连手机，或选「无线连接」。
2. 手机开启「开发者选项 → USB 调试 / 无线调试」。Android 11 及以上可直接用「无线调试 → 使用二维码配对设备」扫电脑上的二维码，自动配对连接。
3. 需要伴侣 App 时安装 `app-debug.apk`，与电脑在同一 Wi-Fi 下扫码建立加密连接。伴侣 App 覆盖安装会保留已配对的电脑。

**本版说明**

- 测试版**已内置永久激活码，无需手动激活**，录制等专业版功能直接可用；在「设置 → 版本与授权」点击撤销后可选择不再自动激活。
- 本版为 **debug 签名的测试版**，未做代码签名与公证；macOS 首次打开可能需要在「系统设置 → 隐私与安全性」中允许，Windows 可能提示 SmartScreen。
- 未做自动更新：升级请回到本页面下载新版本。
- 镜像画面方向默认跟随手机旋转，打开横屏游戏会自动转为横屏。
- 会话进行中可用全局快捷键（Ctrl/⌘ + Alt + S 截图、+ R 录制开关、+ D 轮换方向），组合可在「设置」中修改。

**校验与透明**

- 每个平台的 `SHA256SUMS-<平台>.txt` 为对应安装包的校验值，建议下载后核对。
- `sbom-cargo-*.json` / `sbom-npm-*.json` 为依赖清单（SBOM）。

测试版仍在迭代，遇到问题请在本仓库提 Issue，并附上「设置 → 诊断」导出的诊断包（已抹去序列号、配对码与文件路径）。

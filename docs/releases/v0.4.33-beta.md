## 结构层按重构预览 1:1 复刻（X10-153）

在 v0.4.32 采纳预览视觉语言之后，本版把**结构层**也按 `docs/ui-redesign/mirrordock-rebuild-preview.html` 逐一对齐，解决「新版本离预览版还差很远」的反馈。分组、顺序、19 个视图与预览 NAV / CTX_VIEWS 完全一致。

- **侧栏**：移除「我的设备」设备树与可折叠分组，改为预览的静态分组标题 + 常显导航项（设备 / 镜像与会话 / 内容与传输 / 系统）。底部改为折叠按钮 + 「本地版 · 无需账号」。
- **标题栏**：品牌徽标「MD」、去掉英文副标题；右侧「主题 · …/帮助」文字按钮改为图标按钮（太阳 / 帮助），保留主题下拉与帮助跳转；搜索框居中。
- **情境右栏**：改为仅设备相关视图显示（连接与授权 / 设备信息 / 多端 / 镜像控制 / 投屏演示），内容为排查要点、诊断快照、会话概览、通道与画质、演示边界等情境信息，全部接真实状态、无演示数据；其余视图不占位（消除空栏 280px）。
- **折叠态**：56px 图标栏，标签与分组标题隐藏，与预览折叠行为一致；窄窗口（<1200px）右栏自动隐藏。

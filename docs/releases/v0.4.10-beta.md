# MirrorDock v0.4.10-beta

## 本版更新内容

**桌面端功能与 0.4.9 完全相同**，没有任何功能变化。这一版是为了把新版手机伴侣 App（0.3.1）一起发出来。

### 手机伴侣 App 0.3.1：界面整体升级

用设计规范工具审计了安卓端，结论是**视觉问题源自缺少统一的设计令牌**，而不是审美问题。实测发现 `activity_main.xml` 里有 **124 处硬编码尺寸**、字号散落 **12 种**（含 11.5 / 12.5 / 13.5 / 14.5 这类随手值）。这次把它们全部收敛为一套令牌。

**看得更清楚**

之前有四处灰色文字在浅色背景上对比度不足，读起来发虚（实测 2.15:1 – 2.60:1，标准要求 4.5:1）。现已全部达标（4.72:1 – 6.00:1）。同时卡片加了细描边 —— 此前卡片与背景的亮度差只有 1.10:1，边界其实看不清。

**深色模式（跟随系统）**

手机切到深色外观时，App 会自动换成深色配色，不用手动设置。这是此前完全没有的能力。

**按钮更好按了**

之前有 11 处按钮小于 Android 建议的最小触控尺寸（有的只有 40dp 甚至约 20dp），现在统一到 48dp。

**中文排版修正**

- 按钮与标签去掉加粗 —— 中文加粗是"描边加粗"，小字号下笔画会粘连
- 去掉一处字母间距设置 —— 它的本意是让拉丁字母更透气，中文字面加字距反而破坏紧凑感
- 正文行距放宽 1.3 倍（中文比英文需要更多行距）

**首次显示版本号**

此前 App 里**任何地方都看不到版本号**。现在设置页底部有一行：

```
关于 MirrorDock 伴侣                    0.3.1（18）
```

- **点一下**展开完整信息（含 Android 版本与处理器架构）
- **长按**复制到剪贴板 —— 反馈问题时直接粘贴就行，不用手打

版本号刻意**不加"检查更新"按钮**：伴侣 App 随电脑端一起发布，没有独立的更新渠道，加了按钮只会让人以为点了会更新。改为在界面上说明更新方式。

### 手机伴侣 App 0.3.1：版本号显示

设置页 → 底部 → 「关于 MirrorDock 伴侣」

---

MirrorDock 桌面镜像工具测试版。本地优先：画面、截图、录像与文件传输只经过你自己的数据线或局域网，不上传任何服务器。

**这一版的重点是手机伴侣 App**，桌面端功能与 0.4.9 一致。

**下载哪个文件**（文件名含版本号，按后缀识别即可）

- Windows：`...-setup.exe`（安装版）或 `....msi`
- macOS（Apple 芯片 M1 及以后）：`..._aarch64.dmg`
- macOS（Intel）：`..._x64.dmg`
- Linux：`....AppImage`（免安装）/ `.deb` / `.rpm`
- **手机伴侣 App：`MirrorDock-companion-0.4.10.apk`**（内含 0.3.1）

**安装后怎么开始**

1. 电脑端打开 MirrorDock → 用数据线连手机，或选「无线连接」。
2. 手机开启「开发者选项 → USB 调试 / 无线调试」。Android 11 及以上可直接用「无线调试 → 使用二维码配对设备」扫电脑上的二维码。
3. 需要伴侣 App 时安装 `MirrorDock-companion-0.4.10.apk`，与电脑在同一 Wi-Fi 下扫码建立加密连接。**覆盖安装会保留已配对的电脑**，直接装即可。

**本版说明**

- 测试版**已内置永久激活码，无需手动激活**；在「设置 → 版本与授权」点击撤销后可选择不再自动激活。
- 本版为 **debug 签名的测试版**，未做代码签名与公证。
- 未做自动更新：升级请回到本页面下载新版本。
- 受保护内容（支付、密码页）系统会屏蔽为黑屏。

**校验与透明**

- 每个平台的 `SHA256SUMS-<平台>.txt` 为对应安装包的校验值，建议下载后核对。
- `sbom-cargo-*.json` / `sbom-npm-*.json` 为依赖清单（SBOM）。

测试版仍在迭代，遇到问题请在本仓库提 Issue，并附上「设置 → 诊断」导出的诊断包（里面含版本号）。

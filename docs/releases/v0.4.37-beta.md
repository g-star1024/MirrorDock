## 修复

- **主题切换菜单被内容遮挡**：移除毛玻璃 backdrop-filter（6 处）并提升标题栏层级。玻璃 Aurora 主题下，主题菜单弹层与下拉浮层曾被锁定在卡片层叠上下文内——表现为「主题切换被挡住」「下拉展开错位被下方内容穿透」，本版彻底修复。
- **设置开关样式对齐预览**：勾选框纯 CSS 拉皮为预览同款 28×16 胶囊拨动开关，交互逻辑零改动。
- **主题卡色条对齐预览**：五套主题的色条色值与顺序逐字对齐预览 dots 规格。
- **步骤圆点错行修复**：设备中心「在电脑上安心使用手机」三步骤的蓝色圆点恢复与标题同行（此前因 CSS 覆盖块冲突，圆点独占一行悬在标题上方）。
- **按钮与文字贴边修复**：伴侣扫码配对/常驻通道按钮组、关于卡、诊断包卡、品牌引导卡卡尾说明等处统一补齐间距；新增通用规则防止同类问题复发。
- **帮助中心正文贴边修复**：展开文章的内容不再贴卡片左右边缘与底部。
- **相册目录 chips 圆角**：由药丸形（13px）改回预览同款小圆角。
- **设备卡按钮布局**：设备中心 Hero 卡的按钮恢复横排排列（此前被旧规则强制竖排）。

## 说明

- 手机已连接 USB 但设备中心不显示时，请依次尝试：点连接页「重新检查」→ 解锁手机查看「允许 USB 调试」弹窗（换电脑后需重新授权）→ 确认数据线可传输数据 → 重启客户端。

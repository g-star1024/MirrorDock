# MirrorDock v0.4.22-beta

## 修复

### 桌面模式录制：开始录制后镜像闪退、白屏（X10-103）

在桌面（虚拟屏）模式下点「开始录制」，镜像窗口闪退并白屏。根因是上一版让录制进程自建第二块虚拟屏并重新拉起应用——应用被「搬」到第二块屏，正在显示的那块屏随即变白、表现为闪退。

本版改为：录制进程**不再自建虚拟屏、也不重复拉起应用**，而是直接捕获正在显示的那一块虚拟屏的画面。修复后开始录制不影响镜像窗口，且能录到虚拟屏上的真实内容。

## 实测验证

- 桌面模式开始录制：镜像窗口全程不闪退，录到 1920×848、约 23fps 的真实游戏画面。

## 升级

- **自动更新**：打开应用按提示升级到 0.4.22。
- **手动安装**：从 Release 资产下载对应平台安装包覆盖安装即可。
- **完整性**：四平台安装包均带 Ed25519 签名校验，更新通道安全。

- **重要修复：关闭镜像窗口不再连带退出整个客户端**。部分 macOS 上结束镜像时整个应用直接消失——根因是新版 macOS 强制要求输入法相关系统调用必须在主线程执行，而客户端在后台线程做了这个调用，系统直接把进程杀掉。现已把这类调用全部移到主线程，并加了一层保险：无论如何关闭窗口，应用都只最小化到菜单栏/托盘，退出仅限托盘菜单。
- **新增：无线断线自动重连**。手机熄屏一段时间后从 Wi-Fi 消失、镜像因此中断——现在客户端会持续等待手机回网（最多 15 分钟），点亮手机后镜像自动恢复，并在会话列表和通知里说明进度。可在设置中关闭。
- **新增：应用内自动更新**。「设置 → 关于 MirrorDock → 检查更新」可一键升级：发现新版本后自动下载、校验数字签名并安装，重启即完成。不再需要每次手动下载安装包。
- **新增：帧率上限**。三档画质之外，可把帧率锁定为 60 / 30 / 24——老手机更凉快，长时间会话更省电。默认「跟随设备」不变。
- **新增：手机键盘布局一键直达**。打字没反应或字符全错时，点「设置 → 键盘直输」里的「手机键盘设置」按钮，直接打开手机的「实体键盘」页面确认布局（无需手动找设置入口）。
- **Linux 版随包内置 scrcpy**：不再要求自行安装 scrcpy；仅需发行版提供少量运行库（见 README）。

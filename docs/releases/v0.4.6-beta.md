# MirrorDock v0.4.6-beta

## 本版更新内容

### 桌面模式按设备设置 + 虚拟屏启动应用（X10-71）
- **桌面模式**（在手机上创建独立虚拟显示器，电脑画面不被手机操作打断，类 DeX，需 Android 10+）现在**按设备单独保存**：多台设备不会都开桌面模式，「桌面模式开关 + 虚拟屏启动的应用」跟随每台已开启的设备，不再共用一份全局设置。
- 虚拟屏启动应用的下拉改为**显示应用名称**（首选 `scrcpy --list-apps` 取可启动应用 + 名称，失败回退 `pm list packages -3` 包名），小白用户不再面对裸包名。

### 修复：充电状态被桌面端掩盖（BUG-充电掩盖）
- 移除无线「保持唤醒」中 `dumpsys battery set usb 1` 伪造充电的杠杆——该写法会在切换连接（无线→USB）后复位静默失败，使手机卡在「充电中」的全局 mock 状态，真实充电被掩盖、无法充入。
- 无线屏幕常亮改由 scrcpy `--stay-awake` 覆盖；桌面端不再伪造任何充电状态，手机电量 / 充电真实可见。

### 伴侣 App
- 维持 0.2.5 不变（本版未改动伴侣端代码；APK 随桌面发版一并重打包，资产名 `MirrorDock-companion-0.4.6.apk`）。

### 升级提示
- 仍在 0.4.0 或更早版本的用户，应用内「检查更新」可能提示拉取失败（历史版本的更新源不含测试版）；请从官网或发布页手动安装一次 0.4.6，之后即可正常自动更新。

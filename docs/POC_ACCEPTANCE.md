# MirrorDock POC 真机验收记录

每次执行只测试设备所有者已显式授权的手机。本记录不应包含屏幕截图、配对码、剪贴板、账号或输入内容。

## 准备

1. 记录测试机、Android 版本、OEM、桌面系统、MirrorDock commit 和连接方式；不记录 IMEI、电话号码或账号。
2. 对 USB，开启 USB 调试并在手机上允许本机；对 Wi-Fi，使用 Android 11+ 的无线调试配对，确认同一局域网。
3. 确认 `adb devices -l` 中目标序列号状态为 `device`。
4. 运行 `scripts/measure-session.sh <serial>`。它会写入忽略的 `test-runs/`，仅包含时间、工具版本和 scrcpy FPS 日志。

## P0-05 USB 验收

| 检查项 | 通过标准 | 结果 | 证据位置 |
| --- | --- | --- | --- |
| 首帧 | 从点击“开始镜像”到出现画面少于 3 秒 | 待测 | 本地日志目录 + 人工计时 |
| 鼠标与键盘 | 在非敏感测试页面完成点击、滚动、文字输入；不操作锁屏或受保护内容 | 待测 | 人工观察 |
| 拔线恢复 | 拔线后 UI 显示可恢复状态；重新连接并重新授权后可再次镜像 | 待测 | 人工观察 |
| 撤销授权恢复 | 手机撤销 USB 调试授权后，MirrorDock 不再启动会话并给出重新授权说明 | 待测 | 人工观察 |

## P0-06 Wi-Fi 验收

| 检查项 | 通过标准 | 结果 | 证据位置 |
| --- | --- | --- | --- |
| 配对 | Android 11+ 配对成功，配对码未出现在日志或本机可信列表 | 待测 | 本机应用 UI |
| 独立端口 | 配对端口与连接端口不同时，仍可连接 | 待测 | 人工观察 |
| 重连 | 同一受信任网络下，可用保存的连接地址重新连接 | 待测 | 人工观察 |
| 忘记 | 忘记后本机列表移除并请求 ADB 断开；手机端是否撤销配对由用户在系统设置中控制 | 待测 | 人工观察 |
| 网络切换 | 切换网络后会话断开；回到同一受信任网络后可恢复或给出明确引导 | 待测 | 人工观察 |

把手机放到
这台电脑的桌面上。

MirrorDock 用一根数据线或同一个 Wi-Fi，把 Android 手机的屏幕、声音和键鼠控制接到电脑上。 画面只在你自己的设备之间流动，不经过任何服务器。

在电脑上做手机上的一切

镜像、控制、声音、截图、录像、传文件都在同一个窗口里完成，不用在手机和电脑之间来回换手。

镜像与操控，带一整套快捷键

手机画面实时显示在电脑窗口里，鼠标和键盘反向控制手机。窗口获得焦点时也能直接按快捷键操作， 不必回到主界面。

⌃ / ⌘ + Alt + S ⌃ / ⌘ + Alt + R ⌃ / ⌘ + Alt + D

默认分别是截图、开关录像、轮换显示方向；组合键可在「设置 → 全局快捷键」里改成自己习惯的。

镜像窗口内还有一整套：

修饰键 + H 主屏幕 + B 返回 + S 最近任务 + N 通知栏 + P 电源键 + O 关闭手机屏幕 + ↑ ↓ 音量 + F 全屏 + Q 退出镜像

修饰键同样可以自定义。

  • 有线或无线都能连

    数据线插上即用；同一 Wi-Fi 下也能连接。Android 11 及以上支持系统原生的「使用二维码配对设备」——电脑出码，手机扫一下自动完成配对与连接。

  • 一台手机一张卡片

    连接页按设备归并展示：无论数据线、无线还是离线残影，同一台手机只出现一张卡片，状态即操作。不用了可以在电脑端一键取消授权、清空记录。

  • 画面方向自动跟随手机

    默认不锁定方向。打开横屏游戏或视频，画面自动转横，窗口跟着调整大小；也可以手动锁定某个角度。

  • 把手机声音放到电脑上

    Android 11 及以上可转发系统播放的声音，手机本地自动静音，只用电脑的扬声器。

  • 截图与录像

    截图存到「图片 / MirrorDock」，录像存到「视频 / MirrorDock」。录像由镜像窗口直接写文件，结束时等收尾完成再退出，保证文件能正常播放。

  • 电脑与手机互传文件

    发送的文件进入手机「下载 / MirrorDock」，取回的文件存到电脑的下载目录，只经过数据线或局域网。手机发送后电脑端实时提示；把文件直接拖进 MirrorDock 窗口也一样能发。

  • 手机通知出现在电脑上，还能直接回复

    在手机伴侣 App 打开「通知镜像」（默认关，需你显式授权），新通知会实时显示在电脑「工具」页；自带回复栏的通知可以直接在电脑上打字回复，文本经加密通道送回手机。只发给已配对的电脑、不落盘不进日志，随时可关。

  • 多台设备同时镜像

    每台手机一个独立镜像窗口，互不干扰；托盘菜单逐台列出并结束，设置可选择作用于哪一台，常用设备可收藏置顶。桌面模式与虚拟屏启动的应用按设备单独记忆，应用候选下拉直接显示应用名称。

  • 断线自动重连（数据线与无线）

    数据线被拔掉、手机熄屏后从 Wi-Fi 消失？连接页会明确提示正在等待，插回线或手机回网后自动恢复镜像（最多 15 分钟），点亮手机的那一刻画面就回来。

  • 打字像本地键盘一样

    电脑键盘以实体键盘身份直连手机，不弹全屏软键盘；开始镜像时自动切到能打字的布局，结束后还原你的输入法。聊天软件里回车直接发送。

  • 应用内自动更新

    有新版本时在「设置 → 关于」一键检查并升级，更新包经数字签名校验，不跑篡改过的安装程序。

  • 帧率与画质可调

    三档画质之外，帧率上限可锁定 60 / 30 / 24——老手机更凉快，长会话更省电。

  • 安装 APK

    选择电脑上的安装包一键安装，或者直接把 .apk 文件拖进 MirrorDock 窗口；覆盖安装、保留应用数据，手机上仍需你本人确认。

  • 伴侣 App，加密配对

    手机端安装伴侣 App 后，与电脑建立 TLS 1.3 加密连接并锁定证书指纹；开启「常驻通道」后可免扫码一键重连，应用与文件互传都走这条加密通道。

三步开始镜像

手机端只需要一次设置，之后连上就能用。

  1. 1

    在手机上打开调试入口

    进入「开发者选项」打开 USB 调试；想无线连接就再打开 无线调试。软件里有各品牌的路径指引，菜单名称以手机实际显示为准。

  2. 2

    让电脑连上手机

    插上数据线后在电脑端点「重新检查」；无线则在「无线连接」里生成配对二维码，用手机的「使用二维码配对设备」扫一下。

  3. 3

    开始镜像

    点「开始镜像」，手机画面出现在窗口里。截图、录像、传文件、轮换方向都能在这个窗口里完成。

它做不到什么

这段比功能列表更重要。远程控制类工具最容易含糊其辞的地方就在这里，我们把边界写清楚， 免得你在关键时刻才发现。

  • × 不绕过锁屏，也不解锁 手机在锁屏状态下，MirrorDock 无法点亮并进入系统。它只能在你解锁后接管画面；防止镜像过程中自动锁屏需要你提前把这项打开。
  • × 受保护内容显示为黑屏 支付页面、密码输入、银行与流媒体等应用会由 Android 自行屏蔽，显示和截图都是黑屏。这是系统行为，不是故障。
  • × 没有无人值守的远控 不存在后台静默连接、不存在绕过授权常驻。断开数据线或撤销调试授权，连接就结束。
  • ✓ 画面、剪贴板和口令不写进日志 诊断包在导出前先给你预览，内容已抹去设备序列号、配对码与文件路径，且不会自动上传。
  • ✓ 免费版包含全部镜像功能 截图、文件传输、声音转发、快捷键全部免费；专业版只额外解锁 MP4 录制。测试版已内置激活码，不需要你手动输入。

常见问题

按下话题整理，遇到问题先看这里。

为什么要打开 USB 调试，安全吗？

这是 Android 官方给开发者用的调试通道，MirrorDock 靠它获得画面与控制权限。授权只对你确认过的这台电脑生效，手机上「开发者选项 → 撤销 USB 调试授权」可以随时收回，收回后连接立刻失效。跳过锁屏、破解应用这类事情它做不到，也不会尝试。

无线连接隔一段时间就断了，或者连不上？

手机每次重新打开「无线调试」，端口都会变化，需要重新配对，这不是故障。连接前确认手机与电脑在同一个 Wi-Fi、且该网络没有开启客户端隔离。Android 11 及以上建议直接用扫码配对，电脑会自动发现地址，不用手动抄写。

电脑上没有声音，或手机还在响？

声音转发需要 Android 11 及以上。通话、部分应用与受版权保护的内容受系统捕获策略限制，可能无法转发。另外，开始镜像时手机需处于解锁状态，否则系统不允许捕获音频。开启后声音只在电脑播放，手机本地静音。

打开游戏没有自动变成横屏？

确认「设置 → 显示方向」保持「自动（跟随手机）」。选定了具体角度就会锁定画面方向，只改变电脑上的显示角度，不再跟随手机旋转。

macOS 提示「无法验证开发者」，Windows 弹 SmartScreen？

测试版尚未做代码签名与公证，两个系统都会给出提示。macOS 在「系统设置 → 隐私与安全性」里选择仍要打开；Windows 点「更多信息 → 仍要运行」。正式版会补齐签名。

伴侣 App 扫码时会闪退吗？

v0.1.2 起已修复会导致扫码页闪退的问题。如果仍然异常，App 主界面会出现一张红色卡片，写着上次退出的原因与堆栈，把它截图发到 Issue 即可定位。

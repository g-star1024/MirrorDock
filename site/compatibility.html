Android 版本能力差异

以下差异来自 scrcpy 官方文档并对照本地二进制核实，属系统能力边界，不是 MirrorDock 的缺陷，也不会尝试绕过。

按 Android 版本的能力差异
能力Android < 11Android 11+
系统音频转发 ❌ 自动禁用音频，镜像继续（画面正常） ✅（部分应用受捕获策略限制；开始镜像时手机需处于解锁状态）
FLAG_SECURE 受保护内容（支付、银行、密码输入等） 黑屏（平台行为） 黑屏（平台行为）
无线调试扫码配对 ❌ 无此系统流程（可用 USB） ✅

应用级限制：通话无音频、部分受版权保护的应用可能无声或黑屏。开始镜像时系统会要求设备已解锁（音频捕获前提）。 这些行为界面内都有对应说明。

已知限制

诚实清单：以下条目会随版本更新，不会悄悄消失。

  • ✓ 应用内自动更新（v0.3.0 起） 更新包经 minisign 数字签名校验后才安装。注意：v0.4.0-beta 及更早的客户端内嵌了失效的更新端点，需从发布页手动下载升级一次；v0.4.1 起已修复。
  • ✓ 安装包未做代码签名 签名证书落实前，macOS 会弹 Gatekeeper 提示、Windows 会弹 SmartScreen 提示。应对方式见首页 FAQ 与下载页说明。
  • ✓ 只支持 USB 与同一局域网无线两条路径 跨网段、穿透内网、经服务器中继均不支持。画面与文件只在你自己的设备之间流动。
  • ✓ Linux 安装包需要发行版提供运行库 自 v0.3.0 起 Linux 安装包已随包分发 scrcpy 4.1（自官方源码编译，配套 adb 同为 platform-tools 官方二进制）；但 scrcpy 4.x 依赖的 SDL3 与 FFmpeg 动态库不随包，要由你的系统提供。Ubuntu 25.04+ 可直接安装，22.04 / 24.04 需先获取 SDL3，具体命令见仓库 README 的「Linux 运行库说明」。
  • ✓ 受保护内容黑屏、通话无音频是平台行为 由 Android 系统强制执行（FLAG_SECURE / 音频捕获策略），任何工具都无法也不应绕过，界面内已如实解释。
  • ✓ 无云同步、无遥测 诊断包在导出前可预览，内容已抹去设备序列号、配对码与文件路径，且不会自动上传。
